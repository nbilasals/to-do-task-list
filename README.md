# EduTask - Educator To-Do List Application

## Overview

EduTask is a lightweight, responsive To-Do List application specifically designed for educators to efficiently manage assignment deadlines, student submissions, and daily teaching tasks.

## Features

### Core Functionality

- **Add Tasks**: Create new tasks with titles, deadlines, and LMS integration options
- **Edit Tasks**: Modify existing tasks in-place with a user-friendly edit form
- **Delete Tasks**: Remove completed or unnecessary tasks with confirmation
- **Mark Complete**: Toggle task completion status with visual feedback
- **Smart Sorting**: Automatically organizes tasks by completion status and deadline

## Usage Instructions

### Getting Started

1. **Open the Application**: Load `index.html` in any modern web browser
2. **Add Your First Task**:
   - Enter a descriptive title (e.g., "Grade Math Quiz Chapter 5")
   - Select a deadline date
   - Choose an LMS integration if applicable
   - Click "Add Task"

### Managing Tasks

- **Complete a Task**: Click the "Mark Complete" button (turns green when completed)
- **Edit a Task**: Click the "Edit" button to modify title, deadline, or LMS
- **Delete a Task**: Click the "Delete" button and confirm the action
- **View Statistics**: Check the bottom panel for task completion metrics

### Mobile Usage

- All features work identically on mobile devices
- Forms automatically adapt to single-column layout on smaller screens
- Touch-friendly buttons and input fields
- Swipe-friendly scrolling for long task lists

## Technical Details

### Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Styling**: Custom CSS with CSS Grid and Flexbox for responsive layout
- **Storage**: In-memory storage (can be easily extended to localStorage or external database)
- **Compatibility**: Works in all modern browsers (Chrome, Firefox, Safari, Edge)

## Installation & Setup

### Option 1: Direct Browser Usage

1. Download or clone the project files
2. Open `index.html` directly in your web browser
3. Start adding and managing your tasks immediately
